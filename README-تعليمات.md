# تعليمات نشر وتحديث الموقع

## 1) الرفع إلى GitHub
1. افتح مستودعك `altukwa.github.io` على GitHub من متصفح جوالك أو المتصفح.
2. احذف الملفات القديمة، أو ارفع هذه الملفات فوقها (Upload files) واختر "استبدال" عند التعارض.
3. ارفع **كل** الملفات والمجلدات كما هي: `index.html`, `about.html`, `blog.html`, `post.html`, `contact.html`, ومجلدات `css/` و `js/` و `data/` و `partials/`.
4. تأكد من رفع `logo.png` (موجود عندك مسبقاً في الجذر).
5. بعد الرفع بدقائق سيظهر الموقع محدّثاً على altukwa.github.io.

## 2) إضافة صورتك الشخصية
- ارفع صورتك بصيغة jpg باسم **portrait.jpg** في جذر المستودع (نفس مكان logo.png).
- ستظهر تلقائياً في صفحة "عني".

## 3) ربط قناة يوتيوب (إن رغبت لاحقاً بعرض الفيديوهات)
- إن احتجت لاحقاً قسم فيديوهات، أخبرني وسأضيفه بنفس التصميم.

## 4) نشر مقال جديد (الأهم)
لا تحتاج أي برمجة. افتح ملف `data/posts.json` من GitHub مباشرة (زر القلم ✏️) وأضف كائناً جديداً في بداية القائمة بهذا الشكل:

```json
{
  "slug": "unique-english-slug",
  "title": "عنوان المقال",
  "category": "القرآن والتفسير",
  "date": "2026-08-01",
  "cover": "",
  "excerpt": "ملخص سطر أو سطرين يظهر في بطاقة المقال.",
  "content": "<p>الفقرة الأولى.</p><p>الفقرة الثانية.</p><h2>عنوان فرعي</h2><p>فقرة أخرى.</p>"
}
```
- `slug`: حروف إنجليزية بدون مسافات، يُستخدم في رابط المقال.
- `category`: استخدم واحدة من: القرآن والتفسير / الوعظ والتزكية / السيرة النبوية (أو أضف تصنيفاً جديداً وسيظهر تلقائياً في الفلاتر).
- `content`: النص داخل وسوم `<p>` لكل فقرة، و `<h2>` للعناوين الفرعية.
- احفظ التعديل (Commit changes) وسيظهر المقال فوراً في صفحة "المقالات" والرئيسية.

## 5) تفعيل نموذج "تواصل معي"
النموذج جاهز لكنه يحتاج ربطاً مجانياً بخدمة Formspree (بدون تكلفة):
1. أنشئ حساباً مجانياً على formspree.io من جوالك.
2. أنشئ نموذجاً جديداً وانسخ الرابط الذي يعطيك إياه (يشبه `https://formspree.io/f/xxxxxxx`).
3. افتح `contact.html` واستبدل `YOUR_FORM_ID` بالمعرف الذي حصلت عليه.

## ملاحظات
- الموقع متجاوب بالكامل مع الجوال، ويدعم القوائم التفاعلية والتصفية حسب التصنيف.
- الهوية البصرية: تيل غامق وذهبي على خلفية ورق مخطوطة، مع زخرفة هندسية إسلامية (girih) كعنصر مميز متكرر بأناقة.
